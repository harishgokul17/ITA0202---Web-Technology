💡 Servlet Concurrency Deep-Dive

1. Servlet Singleton Architecture

Servlet containers (Tomcat) instantiate only one single instance of each servlet. All incoming client requests share that same instance.

2. Shared Instance Variables vs Local Variables

Instance fields (e.g., private int count) live on the heap and are shared across all worker threads. Local variables (inside doGet()) live on the thread's call stack and are 100% thread-safe.

3. How AtomicInteger Fixes Race Conditions

AtomicInteger.incrementAndGet() uses CPU-level atomic instructions, preventing threads from reading stale values during concurrent execution.
