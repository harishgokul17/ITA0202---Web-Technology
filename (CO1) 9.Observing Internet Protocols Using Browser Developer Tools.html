Observing Internet Protocols Using Browser Developer Tools

What are Internet Protocols?

Internet protocols are rules that define how data is transmitted across the web. Common examples include:

  • HTTP - used for transferring web pages
  • HTTPS - secure version of HTTP
  • DNS - translates domain names into IP addresses
  • TCP/IP - ensures reliable data transfer

How to Observe Them

Open browser developer tools and go to the Network tab. Refresh a webpage and observe:

  1. Requested URLs
  2. HTTP methods like GET and POST
  3. Status codes such as 200, 404, and 500
  4. Response headers and timings

Example

When you load a webpage, the browser sends requests to the server. Developer tools help you inspect those requests and responses in detail.
