HTML Form Method Demo

Note: HTML forms directly support only GET and POST methods.

1. GET Method Demo

GET method sends form data through the URL. It is used for searching and viewing information.



Observation: After clicking submit, check the browser address bar.

Example URL:

form_method_demo.html?student_name=Arun&department=CSE

2. POST Method Demo

POST method sends form data inside the request body. It is used for login, registration, feedback, and sensitive data.



Observation: In POST method, data will not be visible in the URL.

GET vs POST Simple Difference

Feature GET POST
Purpose To get or retrieve data To send or submit data
Data visibility Data is visible in URL Data is not visible in URL
Security Less secure More secure than GET
Example Search form Login form
